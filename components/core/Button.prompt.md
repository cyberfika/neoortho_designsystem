Primary action control for every NeoOrtho surface — pill-shaped, Poppins SemiBold, purple by default.

```jsx
<Button variant="primary" size="md">Fale com a NeoOrtho</Button>
<Button variant="secondary">Conheça o portfólio</Button>
<Button variant="inverse">Baixar catálogo</Button>
```

Variants: `primary` (roxo #582c83), `secondary` (2px purple outline), `accent` (teal #00b0b9),
`ghost`, `inverse` (white — for use on purple fields). Sizes sm/md/lg. Hover lightens one 20%
step, press darkens one step; there is no scale transform, per the brandbook.
