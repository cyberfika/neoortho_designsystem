Renders an approved NeoOrtho logo file and refuses to go below the brandbook's minimum width.

```jsx
<Logo version="color-medartis" width={240} assetBase="../.." />
<Logo version="white-medartis" width={180} assetBase="../.." clearSpace />
```

Never recolor, distort, or shadow it. Use `white-medartis` on purple fields and photography,
`black-medartis` for single-colour print. `symbol-*` is the ellipse mark alone — brand-token scale only.
