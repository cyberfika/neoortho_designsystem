# Modelo de apresentação NeoOrtho

Twelve slide types reconstructed from `NeoOrtho_Institucional 2026.pdf` (the official
`Template NeoOrtho.pptx` was over the copy limit — see readme.md "Known gaps").

Design width is **1280×720**. Three background masters only: purple field (title, section,
closing), light field (all content slides), full-bleed photography with a protection gradient.

| File | Type | Notes |
| --- | --- | --- |
| `TitleSlide.jsx` | Título | Purple ellipse field, positioning line |
| `IntroSlide.jsx` | Quem somos | Text + ellipse-masked photo |
| `StatsSlide.jsx` | Números | Three-column figure row |
| `ManifestoSlide.jsx` | Manifesto | Purple field, long-form quote |
| `ValuesSlide.jsx` | Valores | Four value cards with line colors |
| `SectionSlide.jsx` | Divisória | Chapter divider on purple |
| `TimelineSlide.jsx` | Linha do tempo | Six-milestone gradient timeline |
| `PhotoStatSlide.jsx` | Foto + número | Full-bleed photo with protection gradient |
| `PortfolioSlide.jsx` | Portfólio | The four product lines |
| `CertificationsSlide.jsx` | Certificações | Materials + certification marks |
| `PresenceSlide.jsx` | Presença | LATAM map with figures |
| `ClosingSlide.jsx` | Encerramento | Obrigado |

`SlideFrame.jsx` supplies the frame + background masters and `SlideLogo`. Every slide carries
the lockup: white `neoortho_logo_branco_medartis.png` on purple/photo, colour version on light.

Open `index.html` for the click-through deck (arrow keys / space).
